Thèmes ​

Le thème de votre site Web définit son apparence générale, ce qui en fait un facteur clé dans la création de la première impression de vos visiteurs.

Les thèmes dans ExalandStore incluent des options telles que les sections de curseur, les sections de produits, les sections de catégories, les liens de pied de page, le contenu du service, les blocs de contenu statique, les barres latérales, le redimensionneur de logo, les paramètres des boutons, les paramètres du blog, le préchargement du site, les options de produits associées, la personnalisation des icônes, les modèles pleine largeur, les options de couleur, les widgets, les dispositions des barres latérales et les en-têtes.

La table theme_customizations prend en charge les personnalisations pour plusieurs thèmes et canaux, vous permettant de définir des paramètres uniques pour chaque combinaison thème-canal. Vous pouvez également filtrer les attributs pour plus de contrôle sur la personnalisation du thème.

Dans cette configuration ExalandStore, le thème de boutique disponible est Par défaut. Lors de la création d'une personnalisation de thème, les types de personnalisation disponibles sont :

  • Carrousel de produits
  • Carrousel de catégories
  • Contenu statique
  • Carrousel d'images
  • Liens de pied de page
  • Contenu des services

Créer des thèmes ​

Étape 1 : Dans le panneau d'administration, accédez à Paramètres >> Thèmes. Cliquez sur Créer un thème.

Étape 2 : Remplissez les informations requises :

1. Nom : Saisissez le nom de la personnalisation du thème. 2. Ordre de tri : Définissez l'ordre de tri. 3. Type : Sélectionnez le type de personnalisation dans la liste déroulante. 4. Chaînes : Sélectionnez la chaîne. 5. Thèmes : Sélectionnez le thème, tel que Par défaut.

Cliquez sur Enregistrer le thème pour continuer.

Carrousel de produits ​

Utilisez Product Carousel pour présenter les produits dans un carrousel réactif.

Configurez les options suivantes :

1. Titre : Saisissez le titre du carrousel. 2. Trier : Sélectionnez l'ordre de tri des produits. 3. Limite : Définissez le nombre de produits à afficher. 4. Filtres : ajoutez des filtres tels que Nouveau, En vedette ou ID de catégorie pour contrôler quels produits apparaissent.

Carrousel de catégories ​

Utilisez Category Carousel pour afficher les catégories dans un carrousel réactif.

Configurez les options suivantes :

1. Trier : Sélectionnez le tri Asc ou Desc. 2. Limite : Définissez le nombre de catégories à afficher. 3. Filtres : ajoutez des filtres tels que ID parent, Nom ou Statut pour contrôler les catégories qui s'affichent.

Contenu statique ​

Utilisez Contenu statique pour ajouter des blocs HTML et CSS personnalisés à la vitrine.

Configurez les options suivantes :

1. Image : Téléchargez une image si le bloc de contenu l'exige. 2. HTML : Ajoutez le contenu HTML statique. 3. CSS : Ajoutez du CSS personnalisé pour le bloc de contenu. 4. Aperçu : Prévisualisez le contenu statique avant de l'enregistrer.

Carrousel d'images ​

Utilisez Image Carousel pour créer des sections de curseur/bannière.

Configurez chaque curseur avec les options suivantes :

1. Titre de l'image : Saisissez le titre du curseur. 2. Lien : Ajoutez l'URL cible du curseur. 3. Image du curseur : Téléchargez l'image du curseur. La résolution recommandée est 1920px X 700px.

Liens de pied de page ​

Utilisez Footer Links pour gérer les liens de navigation en pied de page de la vitrine.

Configurez chaque lien avec les options suivantes :

1. Colonne : Sélectionnez la colonne de pied de page où le lien doit apparaître. 2. Titre : Saisissez le titre du lien de pied de page. 3. URL : Saisissez l'URL du lien. 4. Ordre de tri : Définissez l'ordre d'affichage.

Contenu des services ​

Utilisez Contenu des services pour afficher les points forts des services ou des fonctionnalités sur la vitrine.

Configurez chaque service avec les options suivantes :

1. Titre : Saisissez le titre du service. 2. Description : Saisissez la description du service. 3. Classe d'icône de service : Entrez la classe d'icône utilisée pour l'icône de service.

Général ​

Tous les types de personnalisation de thème incluent la section Général.

1. Nom : Entrez le nom. 2. Ordre de tri : Définissez l'ordre de tri. 3. Chaînes : Sélectionnez la chaîne. 4. Thèmes : Sélectionnez le thème. 5. Statut : Activer ou désactiver le statut.

Filtres ​

Certains types de personnalisation de thème prennent en charge les filtres.

**1. Clé : ** Entrez la clé du filtre. 2. Valeur : Saisissez la valeur du filtre.

Cliquez sur Enregistrer pour finaliser.

Étape 3 : La nouvelle entrée Thème apparaîtra désormais dans la liste des thèmes.

Vous avez maintenant créé et personnalisé avec succès un Thème dans ExalandStore.
